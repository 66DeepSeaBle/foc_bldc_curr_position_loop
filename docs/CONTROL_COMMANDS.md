# 调试控制命令手册

> 本文记录**所有运行期可用的控制命令**。命令是从 **SEGGER RTT 终端**读的，
> 不是串口（串口 USART2 只用于 VOFA 波形输出）。
>
> 代码位置：`Core/app/app.c` 的 `App_PollKeys()` / `App_FeedCommand()` / `App_HandleKey()`。

---

## 0. 怎么连、怎么用

### 0.1 连接方式

1. J-Link 接上板子，打开 **J-Link RTT Viewer**
2. `Connection to J-Link` → 选芯片 **STM32G431RB**
3. 关键一步：**`RTT Control Block` 选 Auto Detection**（或手填 `_SEGGER_RTT`）
4. **`Input` → `Send on Enter` 要勾上**（否则 `t180 d2` 这种命令发不出去）
5. 打开后应该看到开机横幅：

```
===== FOC Control System =====
MCU: STM32G431RBT6, 170MHz
PWM: 20kHz Center-Aligned, control loop: 20kHz
[FW] build 2026-11-02 cal30 20k A2g-W2      ← ★ 判断烧的是哪一版只看这一行
[FW] sensor=hall
```

### 0.2 两条铁律

| 规则 | 说明 |
|---|---|
| **开机前 5 秒只认 `c` 和 `s`** | `App_BootWindow()` 里 5 s 窗口只处理这两个键，其它键这 5 s 内无效 |
| **命令超时 3 秒** | 按了 `t` 之后 3 s 没继续输入就丢弃缓冲（防止"按了 t 忘回车"把后续按键全吞掉） |

### 0.3 按键回显

每按一个键都会回显一行：

```
[KEY] '0' (0x30) st=5 flt=0
```

`st` = 当前状态机状态（见第 8 节），`flt` = 故障标志。

## 1. 命令速查表

### 1.1 移动 / 定位

| 键 | 作用 | 说明 |
|---|---|---|
| `0`～`9` | 走到 `键值 × 45°` | n×45°，例如 `6` = 270°，`0` = 0°。**自动启动**（IDLE 时自动做一次 ALIGN） |
| `z` | 回零（目标 0°） | 固定用 `FOC_POS_DEFAULT_TM_S`(0.85 s) 的定时轨迹 |
| `t<deg>` + 回车 | 定时轨迹走到 `<deg>` | 时长按**速度档**自动算（见 2.1） |
| `t<deg> d<sec>` + 回车 | 定时轨迹，**指定时长** | 时长优先，忽略速度档（见 2.1） |
| `r` | 清故障 + 重新 ALIGN | 目标清零、原地保持。用于 FAULT 后恢复 |

### 1.2 档位调节（调手感的主旋钮）

| 键 | 作用 | 步长 | 范围 | 默认 |
|---|---|---|---|---|
| `]` | 力矩档 **+** | +0.1 A | 0.30 ～ 5.00 A | **3.00 A** |
| `[` | 力矩档 **−** | −0.1 A | 同上 | 同上 |
| `}` | 速度档 **+** | +20 °/s | 10 ～ 1500 °/s | **800 °/s** |
| `{` | 速度档 **−** | −20 °/s | 同上 | 同上 |

> 每次调节都会打印派生出来的四个限幅（见 3、4 节）：
> ```
> [CMD] torque band -> 3.00A (0.30~5.00) | drive=1.70 trim=2.40 damp=0.96 kick=2.40
> [CMD] speed band -> 800 deg/s
> ```

### 1.3 自检 / 诊断

| 键 | 作用 | 停止方式 |
|---|---|---|
| `o` | 进**手动开环**（三相 V/f，手动调压调频） | `t` |
| `s` | 一键**自动 V/f 自检**（15 Hz / 1.0 A / 10 s） | 自动结束或 `t` |
| `p` | **PWM 烟测**（三相各 50% 占空比，转子不转） | `t` |
| `c` | 进**手动盘轴霍尔验证**（驱动强制关断） | 只认 `q` |
| `j` | **+Iq 力矩探针**（+2.5 A 持续 600 ms） | 自动结束 |
| `k` | **−Iq 力矩探针**（−2.5 A 持续 600 ms） | 自动结束 |
| `f` | 翻转开环测试方向（仅开环模式有效） | — |

手动开环（`o`）内部按键：

| 键 | 作用 |
|---|---|
| `u` / `i` | 电压 +/− 0.01（占空比） |
| `n` / `m` | 电压 +/− 0.05（占空比） |
| `h` / `l` | 电频率 +/− 1 Hz |
| `f` | 翻转方向 |
| `t` | 停止 |

### 1.4 日志 / 观测

| 键 | 作用 | 默认 |
|---|---|---|
| `v` | 详细日志开关：`[MAIN]` 从 500/100 ms 变成 **25 ms/条** | OFF |
| `w` | VOFA 波形输出开关 | ON |
| `A` | 到位静音（`po`）开关：到位后关断三相 PWM 判断静止啸叫来源 | **ON** |
| `D` | 翻转 `hall_dir_rev`（霍尔相序方向） | 1 |
| `y` | 翻转 `torque_dir`（力矩方向） | +1 |

> ⚠ `D`、`A` **只认大写**。小写 `d` 与命令 `t180 d2` 里的 `d` 同字，误触发会把整个
> 方向翻反（实测 ALIGN 偏移从 156.1° 变 203.9°，之后全部失控）。

## 2. 移动命令详解

### 2.1 `t<角度> [d<秒>]` + 回车

**语法很宽松**，下面这些写法都等价于"走到 180°，用时 2 秒"：

```
t180 d2
d2 t180          ← 顺序随便
T180 D2          ← 大小写混用
t=180 d:2        ← 分隔符可以是空格、= 或 :
t180d2           ← 分隔符可以完全省略
t-90 d1.5        ← 角度支持负数和小数
```

**执行优先级**（`App_ExecTimed()`）：

```
① 给了 d 且在 0.05～60 s 之间  ⇒  用 d，忽略速度档
② 给了 d 但超范围             ⇒  打一行警告，退回 ① 以外的逻辑
③ 没给 d（或 d 不可用）       ⇒  T = 1.8 × 行程 / 速度档  （FOC_App_EstimateTime）
④ 行程 < 1°                   ⇒  打 "[CMD] already at ... -> hold"，原地保持
```

**特殊情况**：

| 输入 | 结果 |
|---|---|
| 只有 `t` + 回车 | **停止正在跑的开环测试**（历史语义，不是移动） |
| 只有 `d2` + 回车 | 忽略，提示 `missing t<deg>` |
| 乱写 | 提示 `unknown command (use: t<deg> [d<sec>] + Enter)` |

**执行后会打印**：

```
[TM] 7201.2 -> 0.0deg (D=7201.2) in 16.20s | accel 3.60s + cruise 5.40s + decel 3.60s + creep 3.60s | v_cruise=788.8 -> v_app=28.0 deg/s
[TM] armed | tgt=0.0 sgn=-1 Ttick=324056 (16.20s) | vc=788.8 vapp=28.0
[CMD] Set target 0.0deg | now=7201.25 err=-7201.25 -> moving
```

> `[TM] xxx too short for ... -> use yyy` 说明给的 `d` 小于加速度上限允许的最短时间，
> 固件自动放长到 `yyy`（不是报错）。

### 2.2 数字键 `0`～`9`（n × 45°）

**时长按行程比例给**（`App_HandleKey` 里），让巡航速度大致恒定：

```
dur = |误差| / 360    然后夹到 [0.35, 0.85] 秒
```

| 按键 | 目标 | 典型行程 | 时长 | 估算巡航速度 `1.8×行程/T` |
|---|---|---|---|---|
| `0` | 0° | 360° | 0.85 s（上限） | ≈ 762 °/s |
| `1` | 45° | 45° | 0.35 s（下限） | ≈ 231 °/s |
| `2` | 90° | 90° | 0.35 s（下限） | ≈ 463 °/s |
| `4` | 180° | 180° | 0.50 s | ≈ 648 °/s |
| `8` | 360° | 360° | 0.85 s（上限） | ≈ 762 °/s |

> 参考：历史上用固定 1.0 s 时 360° 只有 632 °/s（用户实测"平滑很多"，但比现在的 0.85 s 慢）。

> 为什么不是固定 1.5 s：固定 1.5 s 时 360° 只有 416 °/s、45° 只有 38 °/s，都落在
> 齿槽"一顿一顿"的速度区间（384～681 °/s 是**过不去**的死区，更慢反而一格一格跳）。
>
> 短行程到不了高速是"4 段轨迹 + 加速度上限"的物理限制，不是参数问题。

**必看的一行**：

```
[CMD] Set target 45.0deg | now=44.20 err=0.80 -> ALREADY at target (no motion)
```

出现 `ALREADY at target` 不是 bug —— 位置环在 `|err| < 到位容差` 时**故意撤力矩**，
反复出现的"按了没动"多数是这一条。

### 2.3 定时轨迹的 4 段结构

```
总时长 T  = 加速 ta + 匀速 tc + 减速 td + 逼近 tapp
默认比例  = 2/9     3/9     2/9     2/9
巡航速度  vc ≈ 1.8 × 行程 / T
```

**★ 加减速段时长上限（`foc_control.c` 的 `POS_TM_ACC_TIME_MAX_S`，默认 `0.5f`）**

大角度时 `T` 很长，`ta=td=2T/9` 会到 3~5 秒，转子要在低速区慢慢爬 ⇒ 起步卡顿。
现在 `ta/td` 一旦超过这个上限就**夹住**，且**被砍掉的时间不补回匀速段**
（`tc` 保持 `3/9·T` 不变）⇒ **总时长变短、到点更早**。

| 行程 | `T` 名义 → 实际 | `ta` 改前 → 改后 | `vc` 改前 → 改后 |
|---|---|---|---|
| 360° | 0.81 → 0.81 s | 0.18 → 0.18（不变） | 778 → 778 |
| 900° | 2.03 → 2.03 s | 0.45 → 0.45（不变） | 789 → 789 |
| 1800° | 4.05 → **3.25 s** | 0.90 → **0.50** | 789 → **963** |
| 3600° | 8.10 → **5.50 s** | 1.80 → **0.50** | 789 → **1115** |
| 7200° | 16.20 → **10.00 s** | 3.60 → **0.50** | 789 → **1210** |
| 10000° | 22.50 → **13.50 s** | 5.00 → **0.50** | 789 → **1240** |

> **分界点约 1000°**：行程 ≤ 1000° 时 `ta` 本来就 < 0.5 s，完全不受影响。
>
> ⚠ **代价**：行程不变而时间变短 ⇒ **巡航速度 `vc` 升高**，会**超过速度档**
> （默认 800 °/s，最多 1240 ≈ 1.55 倍）。日志里会打 `v_cruise OVER speed band`。
> 峰值加速度仍只有 ~3800 °/s²（上限 8000），但电机会跑得比以前快。
>
> **想压低 `vc` 又不回到卡顿**：用 `t<deg> d<秒>` 把 `d` 给长一点（`tc` 随名义 T 变大）；
> `POS_TM_ACC_TIME_MAX_S = 0.0f` 则完全关闭，回到原来的 2/9 固定比例。
>
> **★ A/B 结论（2026-11-22 实机手感）**
>
> | 取值 | 版本 | 结果 |
> |---|---|---|
> | **0.5 s** | `A2g-T2` | ✅ **验收通过，定为基线** |
> | 0.8 s | `A2g-T3` | ❌ 用户评价「效果没有 500ms 好」，已回退 |
>
> ⇒ **起步段越短越好**。低速区（齿槽一顿一顿的 384~681 °/s）的停留时间就是
> 卡顿的直接来源，**不要再往 0.8~1.0 s 方向调**；要更快就往 0.3 s 试。

`[TM]` 行里会逐段打出来，触发上限时行尾带标记：

```
[TM] 7201.2 -> 0.0deg (D=7201.2) in 10.00s | accel 0.50s + cruise 5.40s + decel 0.50s + creep 3.60s  <== accel/decel capped; v_cruise OVER speed band | v_cruise=1210.6 -> v_app=28.0 deg/s
```

## 3. 力矩档 `]` `[`（默认 3.00 A）

力矩档不是"一个限幅"，而是**四个限幅的基准**（`FOC_App_SetIqCap()`）：

```
r = 力矩档 / 2.5
drive = 1.70 A        ← 固定，不随档位缩放
trim  = 2.00 × r
damp  = 0.80 × r
kick  = 2.00 × r
```

| 力矩档 | r | drive | trim | damp | kick | 说明 |
|---|---|---|---|---|---|---|
| 2.50 A | 1.00 | 1.70 | 2.00 | 0.80 | 2.00 | A2d 基线（**已淘汰**，长行程末段会卡） |
| **3.00 A** | **1.20** | **1.70** | **2.40** | **0.96** | **2.40** | **当前基线 A2g** |
| 4.80 A | 1.92 | 1.70 | 3.84 | 1.54 | 3.84 | 实测对"粘滞段"**依然无效**（瓶颈不是电流权限） |
| 5.00 A | 2.00 | 1.70 | 4.00 | 1.60 | 4.00 | 上限（过流保护 6 A，留 1 A 余量） |

> ⚠ 力矩档拉大**解决不了**"最后一圈一格一格"。实测 2.50→57.8° / 3.00→57.6° /
> 4.80→60.5°（最后一格的残差），说明瓶颈是"转子被齿槽擒住时参考还在往前跑"。

## 4. 速度档 `}` `{`（默认 800 °/s）

速度档同时决定两件事：

```
巡航速度上限 vmax = 速度档
加速度上限   accmax = 速度档 × 10        （夹到 500 ～ 40000 °/s²）
```

| 速度档 | accmax | 说明 |
|---|---|---|
| 800 °/s | 8000 °/s² | **默认，与历史版本完全一致** |
| 400 °/s | 4000 °/s² | |
| 1500 °/s | 15000 °/s² | 上限 |
| 10 °/s | 500 °/s²（已夹到下限） | |

> ⚠ **不要把默认 800 改掉**。数字键的时长是 `1.8×D/vmax` 算的，改默认值等于直接改
> "按键手感"（试过 648 ⇒ 360° 从 0.85 s 变成 1.00 s）。

速度档也是 `t<deg>` 不带 `d` 时的时长基准：

```
T = 1.8 × 行程 / vmax
再与 sqrt(12.7 × 行程 / accmax) 取大，最后不低于 0.20 s
```

## 5. 自检 / 诊断模式详解

### 5.1 `c` 手动盘轴霍尔验证（不接电）

进这个模式会**强制关断三相 PWM**，可以放心用手转转子。

```c
HallVerify_Enter() → PWM_Output_Disable(); state = IDLE;
```

用途（4 个一次做完）：

| 检查项 | 看什么 |
|---|---|
| ① U/V/W 与合成扇区 | `st` 必须是 1～6，**不应出现 0 或 7** |
| ② 跳变是否合法 | `bad` 计数应恒为 0（跨格/非法相序会 +1） |
| ③ 电角度方向 | `elec` 递增方向 ↔ 期望正转方向 |
| ④ 极对数 | 手转**整整一圈**后 `pole_pairs = (fwd+bwd)/6` |

输出示例：

```
[HALL] #7 U1V0W1 st=3  2->3 FWD elec=95.2
[HALL] U1V0W1 st=3 syn=1 elec=95.2 rev=264.8 fwd=5 bwd=2 bad=0 total=180deg
```

**这个模式下只认 `q`**，按 `q` 退出并重新 ALIGN。

### 5.2 `s` 自动 V/f 自检

固定参数（`board_config.h`）：`15 Hz`、`1.0 A`、`10 s` 自动停。

它会自己分段升压、测等效电阻、验证霍尔是否真的在转。日志用 `[OL]` 前缀：
每 200 ms 一行，含 `|I|=`、三相电流、原始码、三路占空比、母线电压。

### 5.3 `p` PWM 烟测

三相各 50% 占空比（线电压为 0），转子**不会转**。用来确认六路驱动/自举/死区是否正常。
`t` 停止。

### 5.4 `j` / `k` 力矩探针

```c
FOC_Control_SetTorqueProbe(&g_foc, ±2.5f, 600);   /* ±2.5 A，600 ms */
```

**只在 POSITION_LOOP 状态下有效**，否则打 `[PROBE] ignored: state not POSITION_LOOP`。

用途：确定"+Iq 对应哪个机械方向"。期间强制 `torque_dir = +1`，所以施加的电流符号
就是 `probe_iq_A` 本身。看机械角往哪边走即可定符号。

```
[PROBE] START iq=+2.50A dur=600ms torque_dir=1 mech=44.2deg
[PROBE] stop erpm=... mech=...mdeg
```

## 6. 日志怎么读（调试必看）

### 6.1 日志节流

| 标签 | 默认周期 | 开 `v` 后 | 内容 |
|---|---|---|---|
| `[MAIN]` | 运动 100 ms / 静止 500 ms | **25 ms** | 全状态一行（最有用） |
| `[ADCR]` | 5 s | 1 s | ADC 原始码 / 零点 / 换算电流 / 固件 tag |
| `[PROF]` | 1 s | 1 s | 中断负载率与各段耗时 |
| `[ANG]` | 10 ms | 同 | **INFO 级，默认编译掉** |
| `[TM]` `[CMD]` `[POS]` `[PWM]` `[FAULT]` `[PROBE]` `[HALL]` | 事件驱动 | | |

### 6.2 `[MAIN]` 字段速查

```
[MAIN] t=49051ms st=5 flt=0 fc=0x0000 h=4 arr=0 Pos=13.95 Tgt=0.00 err=-13.95 th=150.1
       Id=-0.03 Iq=-1.38 Iqref=-1.06 vd=0.001 vq=-0.035 du=0.525
       spd=0 fb=0 Ipos=0.00 vsp=-0
     | ob=0 vp=0 adv=24.85 dte=1481
     | mv=0 jp=0 vs=0
     | hl=0 gv=0 bh=0 cr=0 tm=9 sl=0
     | tv=-3.1 ff=-1.01 tr=-0.06 vob=-31 po=0
```

| 字段 | 含义 | 调试时的意义 |
|---|---|---|
| `st` | 状态机（见第 8 节） | 5 = 位置环 |
| `h` | 霍尔扇区 1～6 | 15.47° 一格 |
| `arr` | 已到位 | |
| `Pos` / `Tgt` / `err` | 机械角 / 目标 / 误差（度，多圈） | |
| `th` | 电流矢量用的电角度（度） | |
| `Id` `Iq` | 实测 d/q 电流（A） | **`po=1` 时是冻结的旧值，别拿它判断有没有电流** |
| `Iqref` | 实际施加的 q 轴指令（A） | |
| `vd` `vq` | 电流环输出（**占空比量，不是伏特**） | `vq≈0.045` ≈ 1.6 A |
| `du` | U 相占空比 | 0.5 附近 = 零电压 |
| `vsp` | 位置环用的速度（eRPM） | **塌到 0 就说明速度估计失效** |
| `ob` / `vp` | 观测器速度 / 位置差分速度（eRPM） | 两个同时为 0 ⇒ 观测器死了 |
| `adv` | 扇区内进角（度） | **顶在 ±31～33 就是钳位了** |
| `dte` | 距上一条霍尔边沿的毫秒数 | >800 会报 `[POS] BLOCKED?` |
| `mv` | 判定"在动" | |
| `hl` / `gv` / `bh` | 到位死区 / 认输 / 推不动 | |
| `tm` | 定时轨迹段号（0=无，1～9） | |
| `tv` | 沿轨迹的位置误差（度） | **越小越平滑**，`max|tv|` 是 A/B 对比的主指标 |
| `ff` / `tr` | 摩擦前馈 / 微调+阻尼（A） | `Iqref ≈ ff + tr` |
| `vob` | 观测器速度（°/s） | |
| `po` | 到位静音（1=三相全关） | |

### 6.3 `[TM] done` —— 一次移动的客观成绩单

```
[TM] done: max|tv|=48.5deg max|Iqref|=2.27A | band=3.00A drive=3.00A
```

| 指标 | 意义 | 好的标准 |
|---|---|---|
| `max\|tv\|` | 全程最大轨迹跟踪误差 | **越小越平滑**（A2g 基线 40.8°，>50° 说明有问题） |
| `max\|Iqref\|` | 全程最大电流指令 | 若 **= band** ⇒ 一直顶着限幅 ⇒ 力矩不够 |
| `drive` | 驱动侧限幅 | 若 `max\|Iqref\| > drive` ⇒ 会打 `<== DRIVE SATURATED` |

### 6.4 `[PROF]` —— 中断负载

```
FOC@20k  load=54.4%  avg=27.4us max=38.7us    ← 整个 20kHz 中断（周期只有 50us）
VOFA@1k  load=1.7%   avg=17.3us               ← TIM6 组帧
ANG      avg=3.02us                            ← 角度更新
PRE      avg=7.05us                            ← 分频门之前
LAW      avg=11.8us                            ← 外层位置律（10kHz）
CUR      avg=9.5us                             ← Clarke/Park/PI/逆Park/SVPWM
idle=43%                                       ; rttdrop=0 rttbad=0
```

`max` 逼近 50 µs 就必须削东西，否则会掉拍。

## 7. VOFA 波形

### 7.1 上位机配置

| 项 | 值 |
|---|---|
| 协议 | **FireWater**（文本，一行 ASCII，逗号分隔，`\r\n` 结尾） |
| 串口 | STM32 的 **USART2**（PB3=TX / PB4=RX） |
| 波特率 | **921600**，8/N/1 |
| 帧率 | 1 kHz |
| 通道数 | 5 |

### 7.2 两种帧格式（`app.c` 的 `VOFA_FRAME_DIAG`）

**`VOFA_FRAME_DIAG = 1`（当前默认，诊断帧）**

| 通道 | 内容 | 判读 |
|---|---|---|
| ch1 | `Iu` 原始（20 kHz 瞬时，**不滤波**） | |
| ch2 | `Iu` 一阶低通（τ=2 ms） | ch1≈ch2 ⇒ 尖峰是真电流；ch2 明显更平 ⇒ 是噪声 |
| ch3 | `Iqref` 实际施加值（A） | 这里也跳 ⇒ 是控制指令在跳 |
| ch4 | `vsp`（机械 °/s） | 塌到 0 的时刻就是 trim 顶起来的时刻 |
| ch5 | `Pos`（机械 °） | 台阶/冻结 |

**`VOFA_FRAME_DIAG = 0`（传统三相帧）**

| 通道 | 内容 |
|---|---|
| ch1～ch3 | `Iu` / `Iv` / `Iw`（A，经 `VOFA_LPF_TAU_MS` 低通） |
| ch4 | 速度（°/s） |
| ch5 | 位置（°） |

改帧格式只需改这两个宏后重编，**不影响控制**。

### 7.3 帧丢弃

VOFA 是**非阻塞**发送：上一帧没发完，这一帧直接丢弃。

```
[CMD] VOFA wave ON (frames=12345 drops=0)
```

`drops` 持续增长 ⇒ 波特率不够或上位机读得慢。VOFA@1k 中断负载应 < 3%。

## 8. 状态机编号（`st=` 字段）

| 值 | 状态 | 含义 |
|---:|---|---|
| 0 | `IDLE` | 待机，三相不驱动 |
| 1 | `ALIGN` | 对齐：强制电角度 0°注入 Id，把转子拉到已知位置 |
| 2 | `STARTUP` | I-F 开环强拖，等霍尔同步 |
| 3 | `CURRENT_LOOP` | 纯电流环（力矩模式） |
| 4 | `SPEED_LOOP` | 速度环 + 电流环 |
| 5 | `POSITION_LOOP` | 位置环 + 速度环 + 电流环（**正常调试基本都在这个状态**） |
| 6 | `BRAKE` | 刹车（三相下管短路） |
| 7 | `FAULT` | 故障，按 `r` 复位 |
| 8 | `OPENLOOP` | 开环速度测试（`s` 键） |

### 故障码（`fc=` 字段）

| 码 | 含义 |
|---|---|
| `0x0001` | 过流（相电流 > `CFG_OVER_CURRENT_A` = 6 A，连续 4 拍去抖，开通消隐 100 ms） |
| `0x0002` | 启动超时（I-F 拖转 6 s 内霍尔没同步） |

## 9. 典型调试流程

### 9.1 第一次上电（新板 / 新电机）

```
1. 开 RTT Viewer，确认 [FW] build 那一行
2. 5 秒内按 'c'  → 手转一圈，看 st 是否 1..6 连续、bad 是否为 0
                   跑完一圈用 (fwd+bwd)/6 核对极对数
3. 按 'q' 退出 → 自动 ALIGN，等 [ALIGN] 完成
4. 按 's' → 自动 V/f 自检 10 秒，看 [OL] 行的 |I| 和三相电流是否对称
5. 按 'j' → +Iq 探针，看机械角往哪边走
   按 'k' → −Iq 探针
   （方向不对就用 'y' 翻 torque_dir）
6. 按 '3' → 走到 135°，确认能定位
```

### 9.2 调"平滑度"（最常做的）

```
1. 按 'v' 打开 25 ms 详细日志
2. 按某个数字键走一段（比如 '8' = 360°）
3. 等 [TM] done，看 max|tv|
4. 想更平滑：} 降速度档（先降到 600 试），或 ] 升力矩档
5. 再走一次，对比 max|tv| 与 max|Iqref|
   - max|Iqref| 打到 band  ⇒ 力矩不够，上限
   - max|tv| 仍然大        ⇒ 看 [MAIN] 里 vsp/ob/vp 有没有塌到 0
```

> ⚠ **一次只改一个档位**，否则无法判断是哪个起作用。
> ⚠ `max|tv|` 不是平滑度的等效指标 —— 用户真实感受是"看着抖不抖"。

### 9.3 抓波形

```
1. 按 'w' 确认 VOFA ON（日志会打 frames/drops）
2. VOFA+ 选 FireWater、921600、5 通道
3. 当前是诊断帧：ch1/ch2 叠在一起看就知道尖峰是真电流还是噪声
4. 只想看三相电流 ⇒ 把 app.c 的 VOFA_FRAME_DIAG 改 0 重编
```

### 9.4 静止啸叫来源定位

```
1. 走到位，等 arr=1
2. 按 'A' 关掉到位静音（默认是开的，po 会从 1 变 0）
3. 啸叫消失 ⇒ 来自 PWM 载波（20 kHz）
   啸叫仍在 ⇒ 来自机械/电源/其它
```

### 9.5 出现 `[POS] BLOCKED?` 怎么办

```
[POS] BLOCKED? err=-13985mdeg, no hall edge for 800ms (Iqref=-810mA)
```

含义：**差 13.985°（≈0.9 个霍尔扇区）卡住超过 800 ms，只给了 810 mA 破不开**。

| 判断 | 动作 |
|---|---|
| `Iqref` 明显小于力矩档 | 位置环已经"认输"降了力 ⇒ 按 `]` 升力矩档重试 |
| `Iqref` 已经接近力矩档 | 机构真的顶不动 ⇒ 这是机械极限，不是参数问题 |
| 反复出现 | 看 `[MAIN]` 的 `adv` 是否一直顶在 ±33（观测器钳位） |

## 10. 常见"按了没反应"排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 开机 5 s 内按键无效 | `App_BootWindow()` 只认 `c` / `s` | 等 5 s，或直接按 `c`/`s` |
| 按 `t` 之后所有键失灵 | 命令缓冲等待回车 | 按回车；或等 3 s 自动超时 |
| 按数字键但电机不动 | 位置环在容差内**故意撤力** | 看日志是否 `ALREADY at target` |
| 按 `d` 没反应 | 小写 `d` 不是命令，只是命令参数 | 用 `t180 d2`；翻转方向用大写 `D` |
| 按 `e` 没反应 | 该键已删除 | 见 11 节 |
| `j`/`k` 无反应 | 不在 POSITION_LOOP | 先走到位 |
| `[CMD] fault ...` 后全停 | 进 FAULT | 按 `r` 复位 |
| 日志刷太快看不清 | 每 25 ms 一条 | 再按一次 `v` 关掉 |

## 11. 已删除的命令（避免踩空）

| 键 | 原作用 | 删除原因 |
|---|---|---|
| `e` | 精度模式（`arrive_tol` 6° → 1°） | 实测无效：齿槽周期 15°，稳定平衡点在 73.34°，目标 70° 落在两齿槽之间的斜坡上，要按在那里需要持续 1.9 A 对抗齿槽弹簧，而近目标可用电流只有 0.8～1.3 A ⇒ 顶不动，只是多打一堆 `[POS] BLOCKED?`。**定位精度 = 一个齿槽内的残差（实测 1.8～3.4°），要做 ±1° 只能换编码器。** |
